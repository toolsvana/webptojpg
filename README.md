# WebP to JPG Converter

A browser-based tool that converts WebP images to JPG format. Built with Next.js and processes files entirely in your browser.

🔗 **Live Demo:** [WebP to JPG](https://toolsvana.com/tool/webp-to-jpg)

## What it does

This tool converts modern WebP images to widely-compatible JPG format using the HTML Canvas API. Perfect for when you need JPG compatibility.

## Key features

- Converts WebP to JPG format
- Maintains image quality
- Works offline
- No file uploads
- Instant conversion
- Simple interface

## How to use

1. Drop a WebP file or click to browse
2. Conversion happens automatically
3. Download the JPG file

## Technical details

Built with Next.js 16, TypeScript, and Tailwind CSS. Uses HTML Canvas API for image processing.

## Running locally

```bash
npm install
npm run dev
```
